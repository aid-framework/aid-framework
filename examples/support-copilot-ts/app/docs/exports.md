# Exports

## Exporting account data

An account owner can export the account's data from settings, under data and privacy. The
export is prepared asynchronously and the owner is emailed a download link when it is
ready. The link is valid for seven days.

## Export formats

The export is a zip archive of JSON files, one per resource, plus a manifest that names
each file and its record count.

## Export scope

An export covers the whole account. There is no per-user export: a member who needs only
their own records should ask the account owner.

## Deletion

Deleting an account cancels any export that has not finished. An export that already
finished keeps its link until the link expires.
