# `examples/`

Example specs and the apps generated from them — the fastest way to understand what AID Framework is for.

> **Status:** empty. There are no examples yet and the CLI does not exist, so nothing here can be generated.
> Examples land with Phase 0.

## Planned

- **`support-copilot/`** — the RAG + tools support agent from [`docs/design.md` §6.1](../docs/design.md), with
  the spec, the generated `py-fastapi` app, and its eval suite. Phase 0's exit criterion is exactly this:
  *spec → running traced AI endpoint with a passing eval gate*.

Examples are meant to be read, copied, and modified. If you would like to contribute one, please open an
issue first so we can pick a domain that adds coverage rather than duplicating the support-agent example.
