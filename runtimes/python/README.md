# AID runtime — Python

The Python runtime library: the behavior layer imported by apps generated by the
[`py-fastapi`](../../packages/generators/py-fastapi/) generator.

**Provides:** model gateway, prompt registry, retrieval, agent runtime, tool executor, memory, guardrails
engine, eval harness, and OTel GenAI observability/cost — per
[`docs/design.md` §9](../../docs/design.md) (runtime libraries).

**Thin over the ecosystem:** built on **Pydantic AI** for structured output / typed agents, with **LangGraph
or plain async** for the agent loop and **OTel GenAI** for tracing. Only stable public APIs are wrapped, so
the orchestration library stays swappable ([`docs/design.md` §4](../../docs/design.md), principle 5).

**Non-responsibility:** no app-specific prompts, tools, or rubrics.

**Status:** not implemented. Phase 0 ([`docs/design.md` §14](../../docs/design.md)).

Reference: [`docs/design.md` §9](../../docs/design.md).
